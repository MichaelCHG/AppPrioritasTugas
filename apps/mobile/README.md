# prioritas_tugas
Pengintregasian ke mobile belum, tetapi aplikasi sudah dapat running melalui Chrome untuk sementara.
Kedepannya akan dilakukan testing ke mobile device
Setelah di run, aplikasi dapat menampilkan halaman login yang dimana ini bertujuan untuk membedakan para user yang menggunakan aplikasi ini
Database yang digunakan adalah Firebase, dari dashboard database dapat dilihat data-data masing-masing user tetapi nama user tersebut ter-encrypt untuk menjaga privasi user
Saat user login, data dari user lain tidak akan muncul di user yang lain, ini lah salah satu fungsi dari fitur login dan database
